# ShopSense AI

A shopping advisor demo for consumer electronics. You ask a question in plain language, such as "Compare Canon vs Sony". A ReAct agent searches the catalog, and the product panel answers as a grid, a side-by-side comparison, or a bundle.

The catalog is 13 products based on the SAP Spartacus electronics sample data: cameras, camcorders, accessories, and film.

## What it shows

- **ReAct loop.** The agent alternates between reasoning and tool calls until it can answer. It has three tools: `search_products`, `get_product_details`, and `get_category_products`.
- **Generative UI.** The question decides the layout of the product panel: `grid`, `compare`, or `bundle`.
- **Provider fallback.** Moonshot Kimi if `MOONSHOT_API_KEY` is set, otherwise Anthropic Claude if `ANTHROPIC_API_KEY` is set, otherwise a demo mode. Demo mode calls the real catalog tools, but its reasoning text is scripted, not generated by a model.
- **Cart and order.** Products from an answer can be added to a cart and ordered.

## Run it

```bash
python3 -m venv venv
venv/bin/pip install -r requirements.txt
./run_app.sh
```

Then open http://localhost:8501. With no `.env` file the app runs in demo mode. To use a model, copy `.env.example` to `.env` and replace the placeholder key; the placeholders are long enough to be tried as real keys and fail with a 401.

## Where things are

| Path | What it holds |
|------|---------------|
| `app.py` | Streamlit app: chat panel, generative product panel, cart |
| `src/agent/react_agent.py` | ReAct loop, provider fallback, and demo mode |
| `src/agent/tools.py` | The tools the agent calls |
| `src/data/` | Product catalog, cart, and data models |

## Left over from an earlier prototype

This repository started as a B2B commerce agent prototype. These parts come from it:

- `src/agent/planner.py`, `intent.py`, `constraints.py`, `plan.py`, and `executor.py`. `src/agent/__init__.py` imports them, so they load when the app starts, but the app never calls them.
- `demo_cli.py`, `STATUS.md`, `tests/eval/`, `src/api/`, `src/llm/`, and `src/models/`. The app does not load these.

Known issue: in demo mode, bundle answers are still headed "Complete Infrastructure Bundle", a label from that prototype.
